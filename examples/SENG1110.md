### “Logical size” pattern for partially filled arrays (Sales example)（部分填充数组的“逻辑长度”模式（Sales））
Use:
- a fixed physical array size, e.g. `new int[5]`
- a `total` counter to track how many entries are valid
- add: write at `sales[total]`, then `total++` (if space)
- delete: shift left from deletion index, then `total--`
- average: sum only indices `< total`

Core methods shown:
```java
private static int[] sales = new int[5];
private static int total = 0;

private void addSale(int sale) {
  if (total < sales.length) {
    sales[total] = sale;
    total++;
  }
}

private void deleteSale(int position) {
  if (position >= 0 && position < total) {
    for (int i = position; i < total - 1; i++) {
      sales[i] = sales[i + 1];
    }
    total--;
  } else {
    System.out.println("Invalid position for deletion.");
  }
}

private double averageSale() {
  double sum = 0;
  for (int i = 0; i < total; i++) sum += sales[i];
  return sum / total;
}
```

## A school cafeteria wants to analyse the popularity of its menu items during (一所学校的食堂想要分析其菜单项在学生中的受欢迎程度。)
lunchtime. Write a program in Java to input the number of menu items and the number of 
students who purchased each menu item. The program will output the average number of 
purchases, the most popular menu item, and the least popular menu item. If the average 
number of purchases is less than or equal to 20, the program should output “Low Demand”, if 
the average is between 20 and 50, the program will output “Moderate Demand”, and if the 
average is more than 50, then the program will output “High Demand”. If any input is negative or 
zero, the program must show an error message and ask for input again. 
For example, if the input is:
Number of menu items: 4
Number of purchases for each item: 30 45 10 55 
The output will be: 
Average purchases = 35
Most popular item = Item 4
Least popular item = Item 3
Demand is Moderate

import java.util.Scanner;

```java
public class CafeteriaMenuAnalysis {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // ===== 输入菜单项数量（必须 > 0，否则循环重新输入）=====
        int numMenuItems = 0;
        do {
            System.out.print("Enter the number of menu items: ");
            numMenuItems = scanner.nextInt();

            // 输入校验：<=0 属于非法输入
            if (numMenuItems <= 0) {
                System.out.println("Error: Number of menu items must be greater than zero.");
            }
        } while (numMenuItems <= 0);

        // 用数组保存每个菜单项的购买人数
        int[] purchases = new int[numMenuItems];

        // 统计总购买数（用于计算平均值）
        int totalPurchases = 0;

        // ===== 逐个输入每个菜单项的购买人数（必须 > 0，否则重新输入）=====
        for (int i = 0; i < numMenuItems; i++) {
            int purchase = 0;

            do {
                System.out.print("Enter the number of purchases for item " + (i + 1) + ": ");
                purchase = scanner.nextInt();

                // 输入校验：<=0 属于非法输入
                if (purchase <= 0) {
                    System.out.println("Error: Number of purchases must be greater than zero.");
                }
            } while (purchase <= 0);

            // 把合法输入存入数组
            purchases[i] = purchase;

            // 累加总购买数
            totalPurchases += purchase;
        }

        // ===== 计算平均购买数（average = total / n）=====
        double averagePurchases = (double) totalPurchases / numMenuItems;

        // ===== 找出最受欢迎（最大值）与最不受欢迎（最小值）=====
        int maxPurchases = purchases[0];  // 当前最大购买数（初始化为第一个）
        int minPurchases = purchases[0];  // 当前最小购买数（初始化为第一个）

        int mostPopularItem = 1;          // 最受欢迎的菜单编号（从 1 开始）
        int leastPopularItem = 1;         // 最不受欢迎的菜单编号（从 1 开始）

        // 从第二个元素开始比较（i = 1）
        for (int i = 1; i < numMenuItems; i++) {

            // 如果当前购买数更大，则更新 max 和对应 item 编号
            if (purchases[i] > maxPurchases) {
                maxPurchases = purchases[i];
                mostPopularItem = i + 1; // 数组从0开始，题目item从1开始
            }

            // 如果当前购买数更小，则更新 min 和对应 item 编号
            if (purchases[i] < minPurchases) {
                minPurchases = purchases[i];
                leastPopularItem = i + 1;
            }
        }

        // ===== 根据平均购买数判断需求等级（Demand Level）=====
        String demandLevel;
        if (averagePurchases <= 20) {
            demandLevel = "Low Demand";
        } else if (averagePurchases <= 50) {  // 注意：这里包含 20 < avg <= 50
            demandLevel = "Moderate Demand";
        } else {
            demandLevel = "High Demand";
        }

        // ===== 输出结果（Output）=====
        // averagePurchases 是 double，会显示小数（例如 35.0）
        System.out.println("Average purchases = " + averagePurchases);
        System.out.println("Most popular item = Item " + mostPopularItem);
        System.out.println("Least popular item = Item " + leastPopularItem);
        System.out.println("Demand is " + demandLevel);

        // 关闭输入流
        scanner.close();
    }
}
```

## Exam Scores Classification（考试成绩等级统计）

Write a program in Java to read a list of exam scores given as integer percentages in the range 0 to 100 and display:
- the total number of **HD (85-100)**,
- **D (75-84)**,
- **C (65-74)**,
- **P (50-64)**,
- **FF (0-49)**,
- and the **average score**.

Requirements:
- The **average** should be a value of type **double**.
- Use a **negative score** as a **sentinel value** to indicate the end of input.

Example input:
```
98 90 87 86 85 85 78 73 70 72 72 72 66 63 50 33 -1
```

Expected output:
```
Number of HD = 6
Number of D = 1
Number of C = 6
Number of P = 2
Number of FF = 1
Average = 73.75
```

```java
import java.util.Scanner;

public class ExamGradeCounter {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // ===== 各等级计数器（Grade counters）=====
        int hd = 0, d = 0, c = 0, p = 0, ff = 0;

        // ===== 平均数计算用变量（For average）=====
        int sum = 0;      // 总分（Sum of valid scores）
        int count = 0;    // 有效成绩数量（Count of valid scores）

        System.out.println("Enter exam scores (0-100). Enter a negative number to finish:");

        // ===== 不断读取输入，直到读到负数（Sentinel）=====
        while (true) {
            int score = sc.nextInt();

            // sentinel：负数表示输入结束
            if (score < 0) {
                break;
            }

            // 可选：输入校验（如果分数 >100，则认为无效，提示并跳过）
            if (score > 100) {
                System.out.println("Invalid score (must be 0-100). Please enter again.");
                continue;
            }

            // 统计平均数所需数据（sum & count）
            sum += score;
            count++;
```

## Salary Schedule Calculator（工资增长表）

Workers are paid on a salary that is based on their number of years' experience.  
For each year of experience, a percentage increase over the preceding salary is paid:

- Yearly increase rate = **(number_of_years_worked / 2)%**

Example: if starting salary is $20,000 (Year 1):
- After Year 1 → increase **0.5%** (1/2) → Year 2 salary
- After Year 2 → increase **1.0%** (2/2) → Year 3 salary
- After Year 3 → increase **1.5%** (3/2) → Year 4 salary
- ... and so on

Additionally:
- **Every 5 years**, the worker receives an **extra 5% increase**.

Write a Java program that displays the salary per year for one worker.

Inputs:
- starting salary
- number of years in the schedule

Validation:
- If any input is a **negative number**, show an error message and ask again.

```java
import java.util.Scanner;

public class SalarySchedule {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        double startSalary;
        int years;

        // ===== 输入起薪（必须 >= 0）=====
        while (true) {
            System.out.print("Enter starting salary: ");
            startSalary = sc.nextDouble();

            if (startSalary >= 0) break;
            System.out.println("Error: Starting salary cannot be negative. Please try again.");
        }

        // ===== 输入年数（必须 >= 0）=====
        while (true) {
            System.out.print("Enter number of years in schedule: ");
            years = sc.nextInt();

            if (years >= 0) break;
            System.out.println("Error: Number of years cannot be negative. Please try again.");
        }

        // 若 years = 0，则没有年份需要输出
        if (years == 0) {
            System.out.println("No years to display (years = 0).");
            sc.close();
            return;
        }

        double salary = startSalary;

        System.out.println("\nSalary per year:");
        // Year 1 直接是起薪
        System.out.printf("Year %d: $%.2f%n", 1, salary);

        // 从 Year 2 开始：每一年在上一年的基础上加薪
        for (int year = 2; year <= years; year++) {

            // regular raise: (years_worked / 2)%
            // 从 year-1 到 year：years_worked = year-1
            double regularRate = ((year - 1) / 2.0) / 100.0;
            salary = salary * (1.0 + regularRate);

            // extra 5% every 5 years：每做满5年额外 +5%
            // 即完成第5、10、15...年后（进入第6、11、16...年时）
            if ((year - 1) % 5 == 0) {
                salary = salary * 1.05;
            }

            System.out.printf("Year %d: $%.2f%n", year, salary);
        }

        sc.close();
    }
}
```

## Problem Description: Sum of Two Rows in a Matrix (矩阵中两行的和)

Write a method in Java that takes the following parameters:

- A two-dimensional array of integers representing a matrix **A**
- Two integer numbers **r1** and **r2**, representing two different row indices of the matrix

The method should return the **sum of these two rows**.  
The result must be returned as a **one-dimensional integer array**, where each element is the sum of the corresponding elements in row **r1** and row **r2**.

If **r1** or **r2** is **outside the bounds** of the array, the method should return an **array that is not instantiated** (i.e. `null`).

Given the matrix:

1  3  6
-1 4  9
0  8  6

If `r1 = 0` and `r2 = 2`, the returned array should be:

[1, 11, 12]


```java
public static int[] sumRows(int[][] A, int r1, int r2) {

    // ① 边界检查：如果 r1 或 r2 小于 0，或超出数组最大行号范围，就直接返回 null（表示“数组不实例化”）
    if (r1 < 0 || r2 < 0 || r1 >= A.length || r2 >= A.length) {
        return null;
    }

    // ② 获取列数（假设矩阵每一行的列数相同）
    int cols = A[0].length;

    // ③ 创建结果数组（1D），用于存放两行相加后的结果
    int[] sum = new int[cols];

    // ④ 逐列相加：sum[i] = A[r1][i] + A[r2][i]
    for (int i = 0; i < cols; i++) {
        sum[i] = A[r1][i] + A[r2][i];
    }

    // ⑤ 返回相加后的 1D 数组
    return sum;
}
```

## Java Method: Get Row or Column from a 2D Array（从二维数组取某一行/某一列）

Write a method in Java that has as parameters:
- a 2D int array `A` (matrix),
- a String `position` which is `"row"` or `"column"`,
- an int `location` (row index or column index).

Return a 1D int array containing the values of that row/column.  
If `location` is out of bounds, return an array **not instantiated** (i.e., return `null`).

Example: if  
`position = "row"`, `location = 0`, and  
`A = [[1,3,6], [-1,4,9], [0,8,6]]`  
then return `[1, 3, 6]`.


```java
public static int[] getRowOrColumn(int[][] A, String position, int location) {
    // Safety checks（基本检查）
    if (A == null || A.length == 0 || position == null) return null;

    // Normalize input（忽略大小写）
    position = position.toLowerCase();

    if (position.equals("row")) {
        // Check row bounds（检查行下标）
        if (location < 0 || location >= A.length) return null;

        // Note: If rows have different lengths, this still returns that exact row.
        // （如果是不规则数组，也会直接返回该行）
        int[] result = new int[A[location].length];
        for (int i = 0; i < A[location].length; i++) {
            result[i] = A[location][i];
        }
        return result;

    } else if (position.equals("column")) {
        // Need at least one row with columns to validate column index
        // （取列时，要确保每一行都有这个列）
        if (A[0] == null) return null;

        // Check column bounds for each row (to avoid ArrayIndexOutOfBounds)
        // （逐行检查该列是否存在）
        for (int r = 0; r < A.length; r++) {
            if (A[r] == null || location < 0 || location >= A[r].length) return null;
        }

        int[] result = new int[A.length];
        for (int r = 0; r < A.length; r++) {
            result[r] = A[r][location];
        }
        return result;
    }

    // If position is not "row" or "column"
    // （position 不是 row/column 就返回 null）
    return null;
}
```

```java
            total += nh * normalRate + eh * extraRate;
        }

        return total;
    }

    // calcTotalHours: total hours worked in 20 days（计算总工时）
    public double calcTotalHours() {
        double sum = 0.0;

        for (int i = 0; i < employeeWork.length; i++) {
            sum += employeeWork[i].getTotalHours();
        }

        return sum;
    }

    // findMaxDay: return the day (WorkHourDay) with max total hours
    // （找出工时最多的一天，返回该 WorkHourDay 对象）
    public WorkHourDay findMaxDay() {
        WorkHourDay maxDay = employeeWork[0];
        double maxHours = employeeWork[0].getTotalHours();

        for (int i = 1; i < employeeWork.length; i++) {
            double current = employeeWork[i].getTotalHours();
            if (current > maxHours) {
                maxHours = current;
                maxDay = employeeWork[i];
            }
        }

        return maxDay;
    }
```
